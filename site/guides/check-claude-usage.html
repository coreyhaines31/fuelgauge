How to check your Claude usage

Four places show how much of your limit is left, from a page you open once in a while to a line that's always under your prompt.

The short answer

On claude.ai, open Settings › Usage to see your usage and when your limits reset. In Claude Code, run /usage for your plan usage bars. To see it all the time, put it in Claude Code's status line, or let a menu bar app like Fuel Gauge show it and forecast whether you'll make it to the reset.

1. Settings › Usage on claude.ai

Open claude.ai/settings/usage. It shows how much of your session and weekly limits you've used and when each resets. It's also where Pro and Max subscribers turn usage credits on or off and see what they've spent.

Because Claude, Claude Desktop, and Claude Code share the same limits, this page covers all of them.

2. /usage in Claude Code

Type /usage in Claude Code. On Pro and Max you get your plan usage bars and a breakdown of what used them: skills, subagents, plugins, MCP servers, and scheduled loops. Press d or w to switch between the last day and the last week.

Two things to know: the breakdown only counts sessions on this Mac, not claude.ai or other computers, and the dollar figure in the Session block is for API users, not subscribers. If /usage says it's rate limited until a certain time, that's the usage check that's limited, not your work.

In the VS Code extension, the same numbers are in the Account & usage dialog.

3. Claude Code's status line

After every reply, Claude Code hands its status line command your session and weekly usage as percentages, with their reset times. A status line script can print them under the prompt, so you never have to ask. The status line guide has a ready-made script.

4. A forecast in the menu bar

The first three tell you where you are. None of them says whether you'll make it: 55% used with three hours left is fine at one pace and a problem at another.

Fuel Gauge is a free Mac menu bar app that does that math. It reads your limits from Claude Code after each reply, measures your pace, and says "Makes it to reset" or "Runs out around 3:40p". It also covers Codex, Grok Bot, and (if you turn it on) Cursor, and adds the forecast to the status line.

Questions

Where do I see my Claude usage?

Settings › Usage on claude.ai shows your usage and when your limits reset. In Claude Code, run /usage.

Does /usage include my claude.ai chats?

The plan usage bars cover everything, since the limits are shared. The breakdown of what used them only counts Claude Code sessions on this Mac.

Can I see my Claude usage all the time?

Yes. Claude Code passes your usage to its status line after every reply, so a status line script can show it under the prompt. Fuel Gauge also shows it in the menu bar, with a forecast.
