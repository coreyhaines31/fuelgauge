Privacy policy

The Fuel Gauge app

The app collects nothing about you. There's no account, no analytics, and no telemetry.

To forecast your limits it reads what Claude Code, Codex, and Grok Bot already save on your Mac: the usage Claude Code passes to its status line, Codex's session logs in ~/.codex/sessions, and Grok Bot's local usage cache. It keeps a history of those readings in ~/Library/Application Support/Fuel Gauge. It doesn't read browser cookies or need Full Disk Access. Your saved reading history stays on your Mac.

If you turn on the Claude Code status line, Fuel Gauge backs up your Claude Code settings.json before changing it. fuelgauge uninstall-statusline puts it back.

Codex reset tracking is on by default while Codex is tracked. Every five minutes, Fuel Gauge asks the installed Codex CLI for available reset credits using its existing sign-in; this contacts OpenAI. Fuel Gauge does not read or store Codex credentials, and never redeems a reset. Turn tracking off in Settings > Resets; explicit opt-outs are preserved across updates.

Cursor tracking is off by default. If enabled, it requests usage from cursor.com using the Cursor app's existing sign-in. The update check fetches a small feed from GitHub. These services see requests like other web requests, including your IP address.

fuelgauge.app

This website uses the TracerKit tag manager and Headstream for visit analytics, and UserProof to see how visitors use the site (clicks, scrolling and page interactions, not anything you type). TracerKit and Headstream set first-party cookies and browser storage with random visitor and session ids so they can tell new visits from returning ones; UserProof sets no cookies and keeps random ids in your browser's storage. No ad tracking, no personal data sold or shared. It's static pages hosted on Vercel, which keeps standard server logs, and it loads fonts from Google Fonts, which sees that request like any other web request.

Downloads

The app is downloaded from GitHub Releases, or through Homebrew, which downloads it from GitHub. Their privacy policies cover those downloads.
