Privacy policy

Last updated October 2026.

The Fuel Gauge app

The app collects nothing about you. There's no account, no analytics, and no telemetry.

To forecast your limits it reads what Claude Code, Codex, and Grok Bot already save on your Mac: the usage Claude Code passes to its status line, Codex's session logs in ~/.codex/sessions, and Grok Bot's local usage cache. It keeps a history of those readings in ~/Library/Application Support/Fuel Gauge. It doesn't read browser cookies, the keychain, or anything that needs Full Disk Access, and it never signs in to anything. None of it leaves your Mac.

If you turn on the Claude Code status line, Fuel Gauge backs up your Claude Code settings.json before changing it. fuelgauge uninstall-statusline puts it back.

The app's only network request is the check for updates, which fetches a small update feed from GitHub. GitHub sees that request like any other web request, including your IP address.

fuelgauge.app

This website counts visits with Fathom Analytics, which uses no cookies and collects no personal data. It's static pages hosted on Vercel, which keeps standard server logs, and it loads fonts from Google Fonts, which sees that request like any other web request.

Downloads

The app is downloaded from GitHub Releases, or through Homebrew, which downloads it from GitHub. Their privacy policies cover those downloads.
