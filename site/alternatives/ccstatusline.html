ccstatusline alternative

ccstatusline shows where you are. Fuel Gauge shows where you're headed.

ccstatusline is the most customizable status line for Claude Code. Fuel Gauge adds the one thing it doesn't do: a forecast. And it can run underneath it.

Download for Mac View source code

The short version

Keep ccstatusline if you love its widgets: git, tokens, context, cost, and session and weekly usage with reset timers. Add Fuel Gauge for the forecast: whether each limit lasts until it resets at your pace, in the menu bar and as one more line under your status line. Fuel Gauge keeps your existing status line when you turn its line on.

What ccstatusline does well

Everything you might want under the prompt. ccstatusline has widgets for the model, git branch and status, tokens, context use, cost, cache hit rate, and, for limits, session and weekly usage with reset timers and extra usage. You set it up in an interactive screen with npx -y ccstatusline@latest. It's free, MIT licensed, and has about 13,000 stars on GitHub.

Where Fuel Gauge is different

It forecasts. ccstatusline shows how much you've used and when it resets. Fuel Gauge works out whether you'll get there: ⛽ 5h 55% out ~11:50a · wk 41% ok.

It's there when Claude Code isn't. The menu bar shows the same forecast, warns you once per window, and covers Codex, Grok Bot, and Cursor too.

It reads, it doesn't call. Fuel Gauge takes the limits Claude Code already passes to the status line, with no extra requests.

Use both

Claude Code runs one status line command. When you turn on Fuel Gauge's line, it saves your ccstatusline command and runs it first, with the same input, then prints the forecast under it. fuelgauge uninstall-statusline puts ccstatusline back on its own.

Trying it takes a minute

  1. Install Fuel Gauge. brew install --cask coreyhaines31/tap/fuelgauge, or download the app from GitHub and drag it to Applications.
  2. Turn on the status line. From the app, or with fuelgauge install-statusline. It keeps your existing status line and backs up settings.json.
  3. Keep working. A 5-hour limit gets a forecast after about 10 minutes of readings, a weekly one after 3 hours. Until then it says “Learning your pace.”
  4. Keep ccstatusline. It keeps running, with the forecast under it.

Questions

Is ccstatusline free?

Yes. ccstatusline is free and MIT licensed. Fuel Gauge is free too, with the source on GitHub under the FSL-1.1-MIT license.

Can I use ccstatusline and Fuel Gauge together?

Yes. When you turn on Fuel Gauge's status line, it saves your current status line command and runs it first, then prints the forecast underneath. Turning it off puts ccstatusline back on its own.

Does ccstatusline show usage limits?

Yes. It has session and weekly usage widgets and reset timers. It doesn't forecast whether you'll run out before the reset; that's what Fuel Gauge adds.
