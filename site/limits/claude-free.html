Claude Free

Claude Free plan limits

Free has a session limit that resets every five hours. How much fits in a session changes with demand.

The short answer

The Claude Free plan has a session-based usage limit that resets every five hours. The number of messages you can send varies with demand, and Anthropic may add other limits to keep access fair. Claude Code isn't included; Pro gives more usage per session.

Claude Free limits at a glance

Price$0
Session limitResets every five hours
How muchVaries with demand; Anthropic doesn't publish a number
Other limitsAnthropic may add other kinds of limits to keep access fair
Claude CodeNot included
Next step upPro: more usage per session, a weekly limit, and Claude Code

Why the limit moves

On Free, how many messages fit in a five-hour session depends on demand: when lots of people are using Claude, the free allowance shrinks. Long conversations and file uploads use it up faster, since each message carries the conversation before it.

Claude tells you when you've reached the limit. Starting a new chat for a new topic, and keeping prompts and files short, stretches it.

When Free stops being enough

If you hit the limit most days, or want Claude Code, Pro is the next step: more usage per session, a weekly limit on top, and Claude Code included. See Claude Pro limits.

Fuel Gauge forecasts the paid plans' limits through Claude Code, so it's for Pro, Max, and Ultra.

Questions

How many messages does Claude Free give you?

Anthropic doesn't publish a number. It varies with demand and with how long your conversations are.

When does the Claude Free limit reset?

The session limit resets every five hours.

Does Claude Free include Claude Code?

No. Claude Code comes with Pro, Max, Ultra, Team, and Enterprise.
