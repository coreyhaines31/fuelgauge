Claude Pro usage limits

Pro has two limits: a session limit that resets every five hours, and a weekly limit. Claude, Claude Desktop, and Claude Code all draw from both.

The short answer

Claude Pro ($20 a month, or $17 a month billed yearly) gives you at least 5x the per-session usage of the Free plan. Usage is capped by a 5-hour session limit and a weekly limit, shared across claude.ai, Claude Desktop, and Claude Code. Anthropic doesn't publish a message count; how far it goes depends on conversation length, model, features, and effort.

How the two limits work together

The session limit resets every five hours. It's the one you hit in the middle of a long working session.

The weekly limit caps your total for the week, however you spread it across sessions. It resets once a week, so a few heavy days can use it up even if no single session hit its cap.

Both count everything: chats on claude.ai and the desktop app, and every Claude Code request, including Claude Code inside VS Code, Cursor, and JetBrains. Using Claude Code heavily in the afternoon leaves less for chat in the evening.

What uses it up faster

  • Long conversations, since each message carries the history before it
  • Bigger models and higher effort levels
  • Extended thinking, tools, connectors, and web search when you don't need them
  • In Claude Code: long sessions you never /clear, subagents, and scheduled loops

What happens when you hit it

You'll see warnings as you get close. At the limit you can wait for the reset, turn on usage credits to keep working at extra cost, or upgrade to Max 5x, which applies right away.

In Claude Code, if you hit the 5-hour limit mid-response, Claude Code can finish the current step ("Usage limit reached · wrapping up"). On Pro this wrap-up allowance applies at most once per weekly period, and it counts toward your weekly limit.

One trap: if ANTHROPIC_API_KEY is set in your shell, Claude Code bills that API key instead of your Pro plan.

Will you make it to the reset?

A percentage tells you how much you've used. It doesn't tell you whether, at the pace you're going, you'll run out before the window resets. Fuel Gauge does that math: a free Mac menu bar app that reads your Claude Code limits after every reply and says "Makes it to reset" or "Runs out around 3:40p, 1h 20m early". It can put the same line under your Claude Code prompt.

Questions

Does Claude Pro have a limit?

Yes. Pro has a session limit that resets every five hours and a weekly limit. Both are shared across claude.ai, Claude Desktop, and Claude Code.

How many messages do you get on Claude Pro?

Anthropic doesn't publish a number. It depends on how long your conversations are, which model and effort level you use, and which features are on. Pro gives at least 5x the per-session usage of Free.

Does Claude Code use the same limit as Claude?

Yes. Activity in Claude and Claude Code counts against the same limits.

When does the Claude Pro limit reset?

The session limit resets every five hours. The weekly limit resets once a week at a time set for your account; Settings › Usage on claude.ai shows the next reset.
