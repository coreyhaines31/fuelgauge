GitHub Copilot limits

Copilot replaced premium requests with AI credits on June 1, 2026. Each plan gets a monthly allowance that resets on the 1st, at midnight UTC.

The short answer

GitHub Copilot now meters usage in AI credits ($0.01 each), priced per model by tokens. Pro includes 1,500 a month, Pro+ 7,000, Max 20,000, Business 1,900 per user, and Enterprise 3,900 per user, pooled. Allowances reset at 00:00 UTC on the 1st of each month, whatever your billing date, and unused credits don't carry over. Code completions don't use credits.

Each paid allowance is part base, part flex credits; GitHub says flex credits may change over time. 1 AI credit = $0.01.

What happens when you run out

On an individual plan you can upgrade, set a budget for additional usage, or wait for the reset on the 1st. For organizations and enterprises, additional usage is on by default; if it isn't allowed, usage is blocked until the next billing cycle. Subscriptions bought through GitHub Mobile can't buy more credits.

Legacy annual plans and premium requests

Annual Pro and Pro+ plans bought before the change keep premium requests until they expire, then move to Copilot Free: 300 a month on Pro and 1,500 on Pro+, reset on the 1st at 00:00 UTC, with extra requests at $0.04 each.

Does Fuel Gauge track Copilot?

Not yet. Fuel Gauge forecasts Claude Code, Codex, Grok Bot, and Cursor limits. Copilot's monthly allowance is a good fit for a forecast, so it's on the list.

Questions

Does GitHub Copilot still use premium requests?

Only on legacy annual Pro and Pro+ plans. Since June 1, 2026, Copilot meters usage in AI credits.

When do Copilot credits reset?

At 00:00:00 UTC on the 1st of each month, regardless of your billing date. Unused credits don't carry over.

Do code completions use AI credits?

No. Code completions and next edit suggestions don't use credits.
